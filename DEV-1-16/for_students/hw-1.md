### 🏦 Задание 1. Банковская драма с Read Committed

**Сценарий:** Вы управляете банковским счетом. Два клиента одновременно пытаются снять деньги!

1. Создайте таблицу `bank_account` с балансом 1000 рублей
```sql
CREATE TABLE bank_account (
    id SERIAL PRIMARY KEY,
    balance NUMERIC(10,2) DEFAULT 0.00,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
INSERT INTO bank_account (balance) VALUES (1000.00);
```

2. **Клиент А** (сеанс 1): Начинает транзакцию Read Committed, проверяет баланс
```sql
BEGIN ISOLATION LEVEL READ COMMITTED;
SELECT * FROM bank_account WHERE id = 1;
```

3. **Клиент Б** (сеанс 2): Снимает 500 рублей и подтверждает операцию
```sql
UPDATE bank_account SET balance = balance - 500.00 WHERE id = 1;
COMMIT;
```
4. **Клиент А**: Снова проверяет баланс. Сколько денег он увидит? 🤔

**Вопрос:** Почему баланс изменился прямо на глазах у клиента А?

### 🎲 Задание 4. Русская рулетка с ROLLBACK

**Сценарий:** Хакер пытается украсть все деньги, но его поймали!

1. **Хакер** начинает транзакцию и "крадет" все деньги из банка
```sql
BEGIN;
UPDATE bank_account SET balance = 0 WHERE id = 1;
SELECT balance FROM bank_account WHERE id = 1; -- Показывает 0!
```

2. **Система безопасности** обнаруживает атаку
3. Вместо COMMIT делаем ROLLBACK - деньги возвращаются!
```sql
ROLLBACK;
SELECT balance FROM bank_account WHERE id = 1; -- Магия! Снова 1000!
```

**Эксперимент:** Что произойдет с балансом после отката?

### Задание 1. Книги и авторы
Получить список всех книг с их авторами. Показать название книги и полное имя автора.

**Ожидаемый результат:**
| title | author_name |
|-------|-------------|
| Война и мир | Толстой Лев Николаевич |
| Муму | Тургенев Иван Сергеевич |
| Сказка о царе Салтане | Пушкин Александр Сергеевич |
| Трудно быть богом | Стругацкий Аркадий Натанович |
| Трудно быть богом | Стругацкий Борис Натанович |

```sql
SELECT title, 
       last_name || ' ' || first_name || 
       CASE WHEN middle_name IS NOT NULL 
            THEN ' ' || middle_name 
            ELSE '' 
       END AS author_name
FROM books 
NATURAL JOIN authorship 
NATURAL JOIN authors
ORDER BY title, seq_num;
```
