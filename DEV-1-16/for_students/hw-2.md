## 🎪 Курсоры и циклы

### 🌀 Задание 6. Курсор по авторам
Создайте функцию `process_authors()` с курсором:
- Объявите курсор для выборки всех авторов
- Для каждого автора подсчитайте количество книг
- Выведите информацию через `RAISE NOTICE`
- Закройте курсор корректно

**Шаблон:**
```sql
DECLARE
    author_cursor CURSOR FOR SELECT ...;
    author_record RECORD;
BEGIN
    OPEN author_cursor;
    LOOP
        FETCH author_cursor INTO author_record;
        EXIT WHEN NOT FOUND;
        -- ваш код
    END LOOP;
    CLOSE author_cursor;
END;
```

## 💡 Полезные функции PL/pgSQL

```sql
-- Работа со строками
CONCAT(), SUBSTRING(), POSITION(), REGEXP_REPLACE()

-- Работа с массивами  
ARRAY[], array_append(), array_length()

-- Информационные функции
FOUND, ROW_COUNT, GET DIAGNOSTICS

-- Исключения
RAISE EXCEPTION 'Ошибка: %', variable_name;
```
